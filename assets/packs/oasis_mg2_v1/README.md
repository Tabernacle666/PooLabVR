# OASIS / Mega Geometry 2 — source pack

Pack with 18 original parametric GLB 2.0 models, material partitions, stable named sockets, versioned sidecars, provenance, and four deterministic placement recipes. Right-handed glTF Y-up in meters. PNG alpha cutouts are embedded in vegetation files only. No GPU clusters/CLAS are cooked.

Rebuild source files: `node tools/generate_oasis_mg2_assets.mjs` from repository root. The pack owns only `assets/packs/oasis_mg2_v1/` and this generator; it does not change engine runtime or build files. Engine integration owns import contract approval, profiles, meshlets, DXR and MG2 runtime admission. Models are procedural source reference, not final photoreal AAA artwork. Mounts for letter profiles remain to be conformed by the integrator.
